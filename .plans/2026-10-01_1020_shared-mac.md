# Sharing one Mac between many agents and repos

Status: in progress (agent Z) · 2026-10-01

## Symptom
Agents from other repos will use irgo-winvm on the same Mac. Everyone defaults to `irgo-win11`; each
VM takes 8 GiB on a 16 GiB Mac; `app-delete` wipes every caller's staged uploads; delete commands
treat "could not ask UTM" as "nothing to delete".

## Change
- VM ownership + leases (owner, created, last-used); `status`/`doctor` show them; `vm-reap`
  (dry run unless -force; never irgo-win11 or the golden image).
- `irgo-win11` reserved for the owner; other callers get "make your own VM (23 s)".
- Resource guard on vm-create (RAM/disk; cannot tell → refuse).
- Per-VM staging; delete commands distinguish "no such VM" from "could not ask".

## Verify
Unit tests with negative controls; live with one disposable clone at a time.
