# Fix it all: the work order after the 30 Sep cleanup

Status: in progress · 2026-09-30

## Symptom

The owner cannot answer "does glaze work?" without someone re-running it; agents
cannot ask it over MCP; a Windows check takes 1m21s; a known glaze bug (§1b) was
never reported; the repo still has clunky corners. Each item below is one agent's
job, with its own verification.

## The VM rule

The VM is one machine. **Exactly one agent drives it at a time** (the tool's lock,
internal/utmvm/lock.go, refuses a second caller with `busy`). Every other agent
works Mac-side only and hands anything needing Windows to the VM agent or to the
main session.
