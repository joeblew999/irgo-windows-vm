# Guides

One job per page, for someone who has made a first VM in
[Getting started](getting-started.md). Every command is the installed
`irgo-winvm`; a `mise run` command is run in a checkout of this repository.

| Guide | Read it to |
|---|---|
| [Using it](guides/using.md) | understand each command, the exit codes and the costs; make a Linux VM; keep VMs cheap with the golden image and the private cache; share one Mac |
| [For agents](guides/agents.md) | drive it from an AI agent over MCP or HTTP, send a job from Linux, Windows or GitHub Actions, and file issues |
| [Testing](guides/testing.md) | find out whether glaze works on Windows, drive a glaze app with real input, and run the cycle tests |
